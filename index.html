Leitura atual do mercado

O Brasil está em ciclo raro: Selic altíssima (14,75%) com cortes graduais projetados, inflação acima do teto, fiscal deteriorando e juro real próximo de 10,6% — o segundo maior do mundo. Esse ambiente é extremamente favorável à renda fixa em geral. Títulos pós-fixados (Selic) garantem retorno elevado com risco mínimo. O IPCA+ oferece oportunidade de travar taxa real histórica. Prefixados têm apelo se o investidor acredita que a Selic cairá mais do que o mercado projeta.

Cenários futuros

Como cada cenário macroeconômico afeta os títulos

🟢 Cenário base — mais provável (consenso Focus, mai/2026)

Selic cai de 14,75% para ~13% até dez/2026, depois ~11% em 2027. IPCA converge lentamente para ~4% em 2027. Dívida/PIB sobe para ~85% em 2026.

S
Tesouro Selic — excelente no curto prazo
Com Selic a 14,75% e queda gradual, retorno ainda superior a 13% a.a. até meados de 2027. Risco próximo de zero. Ideal para reserva e horizonte até 2 anos.
I+
Tesouro IPCA+ — travar taxa real alta agora é oportunidade histórica
Taxa real de ~7% a.a. + IPCA. Se a Selic cair conforme projetado, o PU sobe e o investidor captura marcação a mercado positiva além do IPCA + taxa travada.
P
Tesouro Prefixado — interessante, com risco de taxa ficar alta
Se a Selic cair como esperado, ganho de capital no vencimento antecipado. Risco: IPCA persistente pode forçar BC a pausar os cortes, prejudicando marcação.

⭐ Cenário otimista — convergência fiscal e desinflação

+
IPCA converge para 3,5% e Selic atinge 10% em 2028
Melhor cenário para Prefixado e IPCA+ longo: PU dispara com queda das taxas. Investidor que comprou IPCA+ 2035 com 7% real e a taxa cair para 5% teria ganho expressivo de capital.

🔴 Cenário pessimista — deterioração fiscal e inflação resistente

!
Selic precisa subir ou fica estagnada acima de 14%
Piora fiscal (dívida rumando a 100% do PIB em 2027 conforme FMI), desancoragem das expectativas. Tesouro Selic vence: retorno garantido. IPCA+ perde no PU mas protege no vencimento. Prefixado sofre mais.
R
Risco Brasil sobe — CDS pressiona taxas longas
Com dívida projetada entre 85–100% do PIB, um evento de mercado pode abrir taxas longas abruptamente. Títulos curtos e Selic ficam protegidos. Evitar Prefixado longo nesse cenário.

Impacto de uma crise fiscal em 2027

O risco real no Tesouro Direto não é calote (improvável — títulos em reais), mas perda de poder de compra e marcação negativa.

Como usar este site

Guia completo para manter tudo atualizado sem precisar programar

Atualizar os dados (fazer 1x por semana ou mês)

1. Acesse Tesouro Transparente e baixe o arquivo precotaxatesourodireto.csv
2. Abra este site e clique em "Carregar dados" no menu lateral
3. Selecione o arquivo baixado
4. Pronto — toda a análise histórica é recalculada automaticamente

Hospedar no GitHub Pages (grátis, permanente)

1. Crie uma conta gratuita em github.com
2. Crie um repositório com o nome: seuusuario.github.io
3. Faça o upload do arquivo index.html (este site)
4. Ative o GitHub Pages nas configurações do repositório → Settings → Pages → Branch: main
5. Seu site estará em: https://seuusuario.github.io

Para atualizar o site no futuro: substitua o arquivo index.html pelo novo. Só isso.

Atualizar os dados macro manualmente

Os dados do Painel Macro (Selic, IPCA, Dívida/PIB etc.) são fixos e precisam ser atualizados por você quando quiser. Fontes recomendadas:

• Boletim Focus — BCB (toda segunda-feira)
• IPCA — IBGE
• Tesouro Transparente

Para editar os valores: abra o arquivo index.html em qualquer editor de texto (Bloco de Notas funciona), busque por "Painel macroeconômico" e altere os números.

Perguntas frequentes

Os dados ficam salvos? Não — o CSV precisa ser carregado a cada visita. Os dados não ficam armazenados no servidor (o site não tem servidor — é só um arquivo HTML).

Posso compartilhar o site? Sim. Qualquer pessoa que acessar pode carregar o próprio CSV e fazer a análise.

Funciona no celular? Sim, mas a experiência é melhor no computador pela quantidade de gráficos.
